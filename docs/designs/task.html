What and why

Every Friday each member gets one email listing the tasks finished that week in their projects, with the pull request for each. Today people have to open Central to see what was done.

Plan

Add a weekly job that collects tasks marked done in the last 7 days per project, renders a plain email and sends it through the mail service already used for invites.

  • No new tables: reads tasks and memberships.
  • Members can turn it off on their Account page.
  • Tests use the fake mail sender; nothing reaches the network.

Items 4

  • D1 Collect last week's finished tasks per member
    Done whena test with three projects returns only that member's tasks.
  • D2 Render the digest email
    Done whenthe text lists title, project and PR link per task.
  • D3 Send it every Friday at 17:00
    Done whenthe scheduler test sends once per member per week.
  • D4 Let members turn the digest off
    Done whena switch on Account stops the email for that member.
